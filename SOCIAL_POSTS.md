## 1. LinkedIn Post (Professional & Technical)

🚀 **Excited to share an open-source project I’ve been crafting: Win11 Net Speed Compact!**

If you've been looking for a clean, minimal, and always-on-top network speed monitor that sits seamlessly on the Windows 11 taskbar without bloat or telemetry, this is for you.

Unlike modern desktop utilities built on heavy web runtimes (Electron/Chromium) that consume 200MB+ of RAM just to monitor network traffic, **Win11 Net Speed Compact** is engineered in Python & Tkinter:
⚡ **Resource footprint:** Sub-30MB RAM and near-zero CPU usage.
🔒 **Security-first:** 100% hash-locked dependencies (`pip --require-hashes`), automated supply-chain audits, build provenance attestations, and zero outbound network telemetry.
🎨 **Customizable layouts:** Single-line horizontal or compact two-row stacked view (`↑ Upload` / `↓ Download` aligned with `RAM%` and `CPU%`).
💬 **Interactive tooltips:** Hover over any metric to see live status (e.g. *"Your upload speed is 12 MB/s"*).
🇧🇩 **Bilingual support:** Complete pure Bengali (বাংলা) and English language switcher.
📦 **Installer & Portable options:** Standard Inno Setup installer wizard (with desktop/start menu shortcuts and uninstaller) plus standalone single-file EXE.

Check out the code, verify the checksums, or grab the latest release:

## 4. Reddit Post (r/windows11, r/Python, r/opensource)

**Title:** Win11 Net Speed Compact - A lightweight, always-on-top network speed + CPU/RAM meter for Windows 11 (Sub-30MB RAM, zero telemetry)

**Body:**
Hey everyone!

I created **Win11 Net Speed Compact**, a lightweight open-source network monitor designed to sit unobtrusively on or near the Windows 11 taskbar.

### What it does:
- Shows live download (↓) and upload (↑) speeds, refreshed twice per second.
- Optional stacked CPU & RAM usage percentages.
- Two layout modes: single-row horizontal or a 2-row stacked format (Upload on top or Download on top) that matches the RAM/CPU column.
- Live hover tooltips (e.g. *"Your upload speed is 12 MB/s"*).
- Dual language support (English & Bengali / বাংলা).
- Custom font colors, font sizes (8–12 pt), font weights, and background colors.
- Both a classic Windows Setup installer wizard and a standalone portable EXE.

### Under the hood:
- Written in Python with Tkinter.
- Sub-30MB RAM footprint (no Electron or Chromium runtime).
- Supply-chain security: All build and runtime dependencies are SHA-256 hash-locked.
- Zero outbound telemetry or background analytics.

GitHub: https://github.com/iqbalmbadhan/Win11NetSpeedCompact  
Releases & Checksums: https://github.com/iqbalmbadhan/Win11NetSpeedCompact/releases  

Would love to hear your feedback, suggestions, or feature requests!
